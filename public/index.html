    Quick answers
    
          
    
            
    
              Does EchoLoom ever read personal Discord user tokens?
              
    Never. Owned channels use official Bot tokens stored in the OS keychain, while unowned community servers use passive read only desktop cache scanning or explicit browser DOM snapshots.
    
            
    
            
    
              How are personal direct messages kept separate?
              
    Invariant INV-02 enforces schema level @me quarantine across search queries, topic clusters, and every MCP tool so personal messages never surface in public engineering outputs.
    
            
    
            
    
              What is included inside /.kiro at repository root?
              
    The committed /.kiro folder ships specs (requirements.md, design.md, tasks.md), automated hooks (hooks.json), and compact domain steering rules (product.md, tech.md, security.md).
    
            
    
            
    
              What does the MIT open source version include?
              
    Everything: Go storage engine, three ingestion adapters, TypeScript MCP server, voiceGate checker, property based tests, and these six fun-isometric stickers.
