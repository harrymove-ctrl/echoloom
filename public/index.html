Four deterministic stages from noisy channel to local binary.

          
Every stage enforces strict privilege isolation so research channels you do not administer stay completely separated from owned project publishing bots.

        


        

          

            
01

            
Three Tier Safe Ingestion

            
Owned servers sync through official scoped Discord Bot tokens stored in macOS Keychain. External servers capture passive desktop cache entries via os.OpenRoot or read only browser DOM snapshots without ever extracting personal localStorage user tokens.

          


          

            
02

            
Local SQLite FTS5 Vault

            
Normalized events write to a 0600 local SQLite WAL database indexed with FTS5 for sub 15 ms queries. Personal @me direct messages are quarantined by schema and blocked from every search, signal cluster, and MCP read by default.

          


          

            
03

            
Kiro Specs, Hooks & Crew

            
Anonymous signal clusters compile directly into structured /.kiro/specs/ contracts, enforced by /.kiro/steering/ boundaries and automated /.kiro/hooks/ quality gates executed by four specialized Kiro Crew agents.

          


          

            
04

            
VoiceGate & Reloadable MCP

            
Drafted guides pass voiceGate scoring against the owner's writing style while stripping AI filler, hidden characters, dashed punctuation, and external verbatim overlap before echoloom-mcp exposes dry run previews for human confirmLive approval.

          

        

      

    


    

      

        

          
Five formal Property Based Testing invariants.

          
Defined in .kiro/specs/requirements.md and verified across 1,000+ generated adversarial inputs per invariant instead of relying solely on happy path examples.

                INV-01
                Attachment SSRF Guard
                Accepts attachment media fetches only over HTTPS port 443 to allowlisted Discord CDN hosts with zero IP literals across up to 3 redirects.
                1,000+ fuzzed URLs
              

              

                INV-02
                @me DM Quarantine
                Default CLI search, signal clusterer, draft context, and MCP read tools return zero rows where guild_id == "@me" across arbitrary interleavings.
                1,000+ mixed store states
              

              

                INV-03
                voiceGate Filter
                Rejects every candidate containing zero width Unicode artifacts, forbidden dash punctuation, raw HTML tags, or more than 12 consecutive external source words.
                1,000+ mutated drafts
              

              

                INV-04
                confirmLive Governor
                Discord write transport executes only when live: true, confirmLive: true, and non empty approvedBy are all satisfied concurrently.
                1,000+ flag permutations
              

              

                INV-05
                Cross Tier Idempotency
                Replaying shuffled duplicate events across Bot API, desktop cache, and browser snapshots converges to identical row counts and FTS5 index entries.
                1,000+ shuffled streams
              

            
          

        

      

    


    

      

        

          
Built on proven open source foundations, with hard security gaps closed.

          
EchoLoom synthesizes battle tested local architecture from five upstream projects for the Kiroween Frankenstein category while fixing real operational vulnerabilities by specification.

        


        

          

            
              

                Reference Ancestor
                What EchoLoom Adopts
                Hardening Upgrade in EchoLoom
              

            
            
              

                openclaw/discrawl
                Pure Go SQLite WAL + FTS5 local indexing, Keychain ACL store, zero network cache concept.
                Closes SSRF gap on attachment URLs, swaps default source = "both" to isolate @me DMs, and hardens SQL URI escaping.
              

              

                jackwener/discord-cli
                Ergonomic analytics verbs (today, recent, top, timeline) and deterministic JSON envelope.
                Removes personal browser user token extraction completely to eliminate account ban risk.
              

              

                jackwener/OpenCLI
                Read only DOM snapshot pattern for browser tabs where Bot access does not exist.
                Standardizes Discord Web message/embed/reply selectors into typed non interactive snapshot imports.
              

              

                ListeningKit (Log)
                Sub 15 ms local reads, reloadable stdio MCP server, voiceGate, and confirmLive governor.
                Applies editorial clarity and dry run outbound safety to Discord engineering communities and Kiro specs.
              

              

                oblien/mindwire
                Daemon orchestration, role isolated multi agent boundaries, and filesystem sandboxing.
                Maps agent separation directly onto four Kiro Crew specialists with automated root guard hooks.
